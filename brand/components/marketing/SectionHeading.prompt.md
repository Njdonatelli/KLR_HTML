Section intro block — small caps eyebrow, large display headline, optional supporting paragraph. Opens every marketing page section.

```jsx
<SectionHeading eyebrow="Our Process" title="From first visit to final walk-through" intro="Seven steps, one team, start to finish." />
```

Set `align="center"` for a centered hero-style intro, `onDark` when placed on a navy or charcoal section.
