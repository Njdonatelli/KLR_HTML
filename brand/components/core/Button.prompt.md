Primary call-to-action button, used for the single most important action on a screen (get a quote, submit, schedule a visit).

```jsx
<Button variant="primary" size="md" onClick={handleSubmit}>Get a Free Quote</Button>
```

Variants: `primary` (solid navy, main CTA), `secondary` (navy outline), `ghost` (text-only), `tan` (warm accent, use for a single standout CTA per page, not repeated). Sizes: `sm`, `md`, `lg`. Pass `onDark` when the button sits on the navy or charcoal surface.
