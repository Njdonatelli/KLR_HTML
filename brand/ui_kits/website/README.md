# KLR Build — Website UI Kit

Marketing-site recreation built from the KLR Build presentation content (no existing website was provided as source). One-page structure: sticky nav → hero → 7-step process → value stats + why-choose-us → testimonial → contact form.

Files: `Header.jsx`, `Hero.jsx`, `ProcessSection.jsx`, `ValueSection.jsx`, `TestimonialSection.jsx`, `ContactSection.jsx`, assembled in `index.html`. Nav links scroll to sections; the contact form shows a confirmation state on submit (no real backend). The hero image is an editable `<image-slot>` placeholder — drop in real job-site photography.
