## Purpose
Assemble and submit a complete HOA architectural-review package **within 3–4 business days of cleared deposit** (flyer promise), so the external approval clock — usually the project's longest dependency — starts as early as possible and doesn't bottleneck the build.

## Scope / Trigger
Fires on the CON-001 trigger when the DES-001 HOA flag = present. Covers requirement gathering, package assembly, CC&R pre-check, submission, approval tracking, and revision cycles. Ends when approval is filed and Production is notified. If DES-001 flagged **no HOA**, record "N/A" and close — this SOP is skipped.

## Roles (RACI-lite)
- **Responsible:** Operations Manager
- **Accountable:** Operations Manager
- **Consulted:** Design Lead (plan revisions), Client (owner-submitted forms / signatures)
- **Informed:** Production Lead (schedule gating)

## Systems & Inputs
- **Dropbox** — package assembly + approval records per TEC-002.
- HOA architectural form + CC&R guidelines; plans/renderings (DES-004); site plan, material/color specs, drainage plan (DES-001); license + insurance (SAF-005).

## Procedure
1. **Confirm requirements** — from the DES-001 HOA flag, obtain the specific HOA's architectural submission form and CC&R guidelines. → *Output: requirements checklist.*
2. **Assemble package** — application, site plan, renderings (DES-004), material/color specs, dimensions + setbacks, drainage plan, contractor license/insurance. → *Output: draft package.*
3. **CC&R pre-check** — validate against guideline restrictions (setbacks, height, materials, coverage) to catch rejections *before* submitting. → *Output: pre-checked package.*
4. **Client review / signature** where the HOA requires owner submission. → *Output: signature-ready package.*
5. **Submit within [3–4 business days]** of cleared deposit (CON-001); log submission date, method, and the HOA's stated review window. → *Output: submission record.*
6. **Track approval** — calendar the review window; follow up at **[7-day]** intervals if silent. → *Output: approval tracker.*
7. **Handle conditions/revisions** — route required changes back to DES-004, resubmit, log the cycle. → *Output: revised submission (if any).*
8. **On approval** — file the approval document in Dropbox; notify Production Lead that HOA-gated scope may be scheduled (PRO-002). → *Output: filed approval + Production notice.*

## Acceptance Criteria / QC
**Package submitted within 3–4 business days of cleared deposit, complete and CC&R-pre-checked; approval tracked to closure; approval filed before any HOA-gated work is scheduled.** Concretely:
- Submission date + expected-decision date logged.
- Package pre-checked against CC&Rs (no avoidable rejections).
- Approval document filed in the project folder.
- Production notified only after approval for HOA-gated scope.

## Exceptions & Escalation
- **Missing info the HOA requires** → targeted DES-001 return capture; don't submit incomplete.
- **HOA denial** → revise via DES-004 and resubmit, or convert to scope change (CON-004).
- **HOA non-responsive past its stated window** → Ops Manager escalates to HOA board / management company.
- **Repeated denials** → Principal + Design Lead for redesign.

## Outputs
Submitted HOA package, approval tracker, filed approval → Dropbox. Gates schedule finalization in **PRO-002**; revisions loop through **DES-004** / **CON-004**.
