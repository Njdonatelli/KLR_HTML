## Purpose
Control every mid-project scope change so it is **priced, margin-applied, and client-authorized in writing before the changed work proceeds** — preventing scope creep, margin erosion, and disputes.

## Scope / Trigger
Fires on any deviation from the executed contract scope (CON-001): client-requested change, unforeseen site condition (subgrade, drainage, utilities), HOA-required revision (CON-002), or material substitution/availability. Ends when the signed change order (CO) is filed and the contract sum/schedule updated.

## Roles (RACI-lite)
- **Responsible:** Operations Manager (or Production Lead for field-originated conditions)
- **Accountable:** Operations Manager
- **Consulted:** Design Lead (design impact/re-pricing), Production Lead (constructability/schedule), Client (authorization)
- **Informed:** Principal (margin/feasibility threshold breaches)

## Systems & Inputs
- **Contractor Foreman** — CO log, contract sum, schedule.
- **Dropbox** — signed COs filed per TEC-002.
- Executed contract (CON-001), current plans (DES-004), estimate method (DES-005).

## Procedure
1. **Log the request** in Contractor Foreman the moment it arises (source + description); **pause affected work** if it can't proceed correctly/safely without resolution. → *Output: CO record.*
2. **Assess impact** — mini-takeoff per DES-005 method (materials, labor, subs) plus schedule delta; apply **target margin**. → *Output: priced CO with schedule impact.*
3. **Present to client** — itemized cost, schedule shift, and revised contract total. → *Output: CO document.*
4. **Obtain written authorization** (signature / e-sign) **before performing changed work. No verbal changes.** → *Output: signed CO.*
5. **Collect payment** per CO terms within the milestone structure (FIN-001). → *Output: CO payment logged.*
6. **Update records** — adjust contract sum + schedule in Contractor Foreman; revise plans (DES-004) if design changed; file the signed CO in Dropbox. → *Output: updated project record.*

## Acceptance Criteria / QC
**No changed work is performed on a verbal or unsigned change.** Concretely:
- Every change captured as a CO before work proceeds.
- CO priced with target margin applied.
- Client written authorization obtained pre-work.
- Contract sum + schedule updated in Contractor Foreman.
- Signed CO filed in the project folder; plans revised if applicable.

## Exceptions & Escalation
- **Emergency / safety condition** requiring immediate action → act to make safe, document immediately, notify client, and ratify the CO retroactively **same day**.
- **Trivial, no-cost clarification** → note in the project log; no CO required.
- **Client disputes an unforeseen-condition CO** → Ops Manager + Principal.
- **CO drops project below margin/feasibility** → Principal decision before proceeding.

## Outputs
Signed change order, updated contract sum + schedule, revised plans → Dropbox + Contractor Foreman. Feeds **FIN-001** (billing) and **FIN-003** (job-cost reconciliation).
