## Purpose
Standardize segmental paver / hardscape installation to a durable, warranty-defensible assembly — correct base, bedding, edge restraint, and jointing — so surfaces don't settle, spread, or heave. Second-highest callback risk after drainage (FLD-002).

## Scope / Trigger
Fires after FLD-002 grade/drainage verification. Covers base construction through final jointing and compaction for pedestrian and light-vehicular segmental paving. Excludes drainage/grading (FLD-002) and poured structural concrete (separate SOP / sub scope).

## Roles (RACI-lite)
- **Responsible:** Production Lead / crew lead
- **Accountable:** Production Lead
- **Consulted:** Design Lead (pattern/layout intent), manufacturer tech (spec edge cases)
- **Informed:** Operations Manager (QC/inspection status)

## Procedure
1. **Confirm prerequisite** — FLD-002 grade/drainage verified + documented. Do not start base otherwise. → *Output: prerequisite check.*
2. **Base construction** — place aggregate to spec depth; compact in lifts to spec; screed to design profile holding FLD-002 slope. → *Output: compacted, screeded base.*
3. **Geotextile** over subgrade where soils require. → *Output: separation layer (if used).*
4. **Bedding layer** — screed [~1"] bedding; **do not compact before laying**. → *Output: screeded bed.*
5. **Lay pavers** to design pattern (DES-004) off string lines; maintain consistent joints; full units first, cuts last. → *Output: laid field.*
6. **Edge restraints** — install on all open edges, spiked per manufacturer. → *Output: restrained perimeter.*
7. **Cuts** — saw-cut clean at borders/penetrations; band as designed. → *Output: finished edges.*
8. **Compact + joint** — plate-compact with protective mat to seat pavers; sweep joint sand; set polymeric sand per manufacturer (moisture/cure). → *Output: seated, jointed surface.*
9. **Final QC** — check slope, joint lines, lippage, surface consistency; clean. → *Output: QC-passed surface + photo record.*

## Acceptance Criteria / QC
**The assembly matches spec at every layer, and the finished surface holds FLD-002 drainage slope with no ponding.** Concretely:
- Base depth + compaction to spec, in lifts.
- Bedding screeded to spec, not pre-compacted.
- Edge restraint on all open edges.
- Pattern/layout per DES-004; joints consistent; lippage within tolerance.
- Polymeric joint sand set per manufacturer.
- Surface slope verified (no ponding); surface photographed.

## Exceptions & Escalation
- **Base/subgrade fails compaction** → over-excavate + rebuild; if soils are the cause, geotech + CON-004.
- **Design pattern infeasible with delivered material** → Design Lead; substitution via CON-004 if needed.
- **Vehicular/structural load beyond standard section** → engineered section required before proceeding.

## Outputs
Completed, QC-passed hardscape + photo record → Dropbox project folder. Feeds **CX-001** sign-off and **CX-002** warranty baseline; deviations route to **CON-004**.
