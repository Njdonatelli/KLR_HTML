## Purpose
Verify all contracted + change-order scope is complete to spec, generate and clear the **internal** punch list, and package the project for client sign-off — so the client walk-through (CX-001) is a confirmation, never a discovery of work KLR should have caught.

## Scope / Trigger
Fires when production phases complete (PRO-002). Covers internal completion review, punch generation/clearance, QC-record verification, cleanup/demobilization, and closeout-package assembly. Ends by triggering CX-001. Does **not** cover the client walk or sign-off (CX-001).

## Roles (RACI-lite)
- **Responsible:** Production Lead
- **Accountable:** Production Lead
- **Consulted:** Crew lead (punch resolution), Design Lead (design-intent questions)
- **Informed:** Operations Manager (CX-001 readiness), Admin/Finance (final billing readiness, FIN-001)

## Systems & Inputs
- **Contractor Foreman** — punch list, completion status.
- **Dropbox** — closeout package per TEC-002.
- Contracted scope (CON-001) + change orders (CON-004), plans (DES-004), FLD QC records (FLD-002/003), daily logs (PRO-005).

## Procedure
1. **Internal completion review** — verify all contracted + CO scope against plans (DES-004). → *Output: completion review.*
2. **Generate internal punch list** — walk with crew lead; capture defects, incomplete items, and cleanup against FLD standards (FLD-002/003 QC). → *Output: internal punch list.*
3. **Resolve + re-inspect** — assign, complete, and re-check each punch item. → *Output: cleared internal punch.*
4. **Verify QC records** — confirm FLD-002/003 photo + drainage-test records are complete and filed. → *Output: QC pack.*
5. **Cleanup + demobilize** — final site cleanup and equipment removal; confirm jobsite condition (FLD-006). → *Output: clean site.*
6. **Assemble closeout package** for CX-001 — as-builts/photos, warranty docs, QC records, final SOV status (FIN-001). → *Output: closeout package → triggers CX-001.*

## Acceptance Criteria / QC
**The client walk-through (CX-001) confirms completion — it never discovers open work KLR should have caught.** Concretely:
- Internal completion review done against contracted + CO scope.
- Internal punch generated **and cleared** before the client walk.
- FLD QC records complete and filed.
- Site cleaned and demobilized.
- Closeout package assembled and CX-001 triggered.

## Exceptions & Escalation
- **Unresolvable item** (e.g., material backorder) → document + client-agreed carry to warranty (CX-002) or return visit; do not hide it.
- **Scope gap vs. contract** → correct, or CON-004 if it's a change.
- **Quality below standard requiring rework** → Production Lead owns; margin impact → Principal.

## Outputs
Cleared internal punch, QC pack, closeout package → Dropbox + Contractor Foreman. Triggers **CX-001**; final costs → **FIN-003**.
