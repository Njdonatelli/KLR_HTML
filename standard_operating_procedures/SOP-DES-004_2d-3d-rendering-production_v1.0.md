## Purpose
Produce client-ready 2D/3D renderings within the **5–7 day** SLA from site assessment (DES-001), accurately representing a **buildable** design so they anchor the estimate (DES-005) and proposal (DES-006). This is the flyer's "Visual Confidence" differentiator and the design phase's SLA engine.

## Scope / Trigger
Fires on the DES-001 handoff (design clock already started). Covers base-model build, design, render production, internal constructability review, delivery, and bounded revisions. Ends with an approved design package feeding DES-005/DES-006. Excludes takeoff/pricing (DES-005) and drone capture (DES-002).

## Roles (RACI-lite)
- **Responsible:** Design Lead
- **Accountable:** Design Lead
- **Consulted:** Production Lead (constructability), Geospatial/Tech Manager (photogrammetry asset import, TEC-005)
- **Informed:** Operations Manager (SLA status), Client (delivery)

## Systems & Inputs
- **Realtime Landscaping** — rendering.
- **3D asset pipeline (TEC-005)** — RealityScan/Blender imports where DES-002/003 ran.
- **Dropbox** — asset storage per TEC-002.
- Design brief + measurements + drainage notes (DES-001); optional photogrammetry model (DES-002/003); HOA/setback flags (DES-001/CON-002).

## Procedure
1. **Verify inputs** complete (DES-001 brief/measurements/drainage; DES-002/003 model if triggered). **Don't start on incomplete data** — the SLA depends on it. → *Output: verified inputs.*
2. **Build the base model** to the measured site (scale-accurate); import geospatial/photogrammetry assets via TEC-005 if present. → *Output: base model.*
3. **Design to brief** — hardscape, structures, planting, water features — respecting setbacks/HOA constraints (DES-001/CON-002) and the drainage strategy (FLD-002). → *Output: design draft.*
4. **Produce renders** — 2D plan + 3D standard view set (overview + key vantage points). → *Output: render set.*
5. **Internal constructability review** — Design Lead + Production input **before** the client sees it; verify buildability and rough alignment with the coming estimate. → *Output: reviewed renders.*
6. **Deliver within the 5–7 day SLA**; handle bounded client revision rounds (**[2]** included; further rounds via scope/CO conversation). → *Output: delivered renders.*
7. **Finalize** the approved design; release to DES-005 (takeoff) + DES-006 (proposal); file assets in Dropbox. → *Output: approved design package.*

## Acceptance Criteria / QC
**No render reaches the client that hasn't passed constructability review — the picture must be buildable and estimatable.** Concretely:
- Renders delivered within 5–7 days of the DES-001 clock start.
- Scale-accurate to the measured site.
- Setbacks / HOA / drainage respected (no un-permittable or undrainable promises).
- Internal constructability review passed before client delivery.
- Revision rounds bounded per policy.

## Exceptions & Escalation
- **Incomplete inputs** → bounce to DES-001; flag SLA risk.
- **Complex model requiring survey-grade capture** → confirm DES-002 done before designing.
- **Excess revision rounds** → scope/CO conversation (CON-004).
- **SLA at risk** → Design Lead / Operations Manager for resourcing or client expectation reset.
- **Design vs. constructability conflict** → Production Lead resolves before delivery.

## Outputs
Approved 2D/3D render set → **DES-005** (takeoff), **DES-006** (proposal); assets filed in Dropbox (TEC-002).
