## Purpose
Capture, in a **single site visit**, everything required to produce renderings (DES-004) and an itemized estimate (DES-005) within the flyer's **5–7 day** SLA — without a return trip. This SOP is the data-integrity gate for the entire design phase; an incomplete assessment breaks the SLA downstream.

## Scope / Trigger
Fires when SAL-003 confirms a consultation appointment. Covers the goals interview, full site measurement, conditions/drainage survey, photo documentation, HOA determination, and the drone-survey decision. Ends when the project record exists and the design clock starts.

## Roles (RACI-lite)
- **Responsible:** Design Lead
- **Accountable:** Design Lead
- **Consulted:** Client (goals, budget, style); Geospatial/Tech Manager (if drone survey triggered, DES-002)
- **Informed:** Sales Lead (handoff close-out); Production Lead (early feasibility flags)

## Systems & Inputs
- **Contractor Foreman** — project record of truth.
- **Dropbox** — project folder per TEC-002 naming/PARA structure.
- **Measurement kit** (tape/laser/wheel); camera; DJI Air 2S + GCP kit on standby for DES-002.
- Qualified lead + notes from SAL-002/SAL-003.

## Procedure
1. **Pre-visit prep** — review SalesRabbit lead + qualification notes; pull parcel/plot plan if obtainable; reconfirm appointment. → *Output: prep brief.*
2. **Goals interview** — capture priorities, must-haves vs. nice-to-haves, style/inspiration, and **confirm budget band** from SAL-002 (reset expectations if misaligned). → *Output: design brief draft.*
3. **Site measurement + conditions survey** — work-area dimensions, existing hardscape/structures, setbacks/easements, utilities (water, electrical, gas for firepits), irrigation, equipment access, staging/disposal. → *Output: field measurements + annotated site sketch.*
4. **Drainage + grade assessment** — slope, low points, runoff paths, downspouts, existing pooling. This is the flyer differentiator and the top callback risk. → *Output: drainage notes (feeds FLD-002 + design).*
5. **Photo documentation** — standard set: every elevation, all problem areas, access route, tie-in points. → *Output: photo set in Dropbox project folder.*
6. **HOA determination** — presence + architectural submission requirements. → *Output: HOA flag + requirements (feeds CON-002).*
7. **Drone-survey decision gate** — trigger **DES-002** if: large/complex lot, significant grade change, 3D model required for design, or access limits manual measurement. Else manual capture is sufficient — record the decision. → *Output: DES-002 trigger or "manual sufficient" note.*
8. **Create + start clock** — open the Contractor Foreman project record; upload all captured data to the Dropbox project folder (TEC-002); **start the 5–7 day design clock** with a due date. → *Output: CF project + design due date.*

## Acceptance Criteria / QC
**The assessment is complete only if DES-004 and DES-005 can start without a return visit.** Concretely:
- Design brief complete: goals, confirmed budget band, in/out-of-scope.
- Full measurement set + site sketch.
- Drainage assessed and documented.
- Standard photo set uploaded to the correct Dropbox path.
- HOA status determined.
- Contractor Foreman project created; design clock started with due date.
- Drone decision recorded (triggered or waived).

## Exceptions & Escalation
- **Inaccessible / locked areas** → schedule brief return or guided client self-capture; do not guess measurements.
- **Scope beyond current capability** → Principal.
- **Survey-grade accuracy required** → DES-002 (drone/GCP) before design proceeds.
- **Budget misalignment surfaced on-site** → reset with client; if unrecoverable, disposition back through SAL with reason.

## Outputs
Design brief, measured site data, drainage notes, photo set, HOA flag → Dropbox project folder + Contractor Foreman. Conditionally triggers **DES-002**, then feeds **DES-004** (renderings) and **DES-005** (estimate).
