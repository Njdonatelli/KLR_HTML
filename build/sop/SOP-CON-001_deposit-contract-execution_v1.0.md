## Purpose
Convert an accepted proposal (DES-006) into a **fully executed, CA-compliant contract** with deposit collected within statutory limits — establishing the legal and financial basis to begin, and triggering the HOA clock (CON-002) and production handoff (PRO-001).

## Scope / Trigger
Fires when the client accepts the proposal (DES-006). Covers contract assembly, CA compliance check, signature, deposit collection, and downstream triggers. Ends when funds clear and CON-002 + PRO-001 are triggered. Does **not** cover mid-project changes (CON-004) or milestone billing (FIN-001).

## Roles (RACI-lite)
- **Responsible:** Operations Manager
- **Accountable:** Operations Manager
- **Consulted:** Principal (non-standard terms); counsel (contract template/legal questions)
- **Informed:** Design Lead (scope lock), Production Lead (incoming handoff)

## Systems & Inputs
- **Contractor Foreman** — contract, deposit ledger, project record.
- **M365 / e-sign** — signature capture.
- **Dropbox** — executed docs filed per TEC-002.
- Approved proposal (DES-006), itemized estimate (DES-005), plans (DES-004), milestone schedule (FIN-001).

## Procedure
1. **Assemble contract** from the approved proposal: scope + itemized estimate (DES-005), plans (DES-004), milestone payment schedule (FIN-001), start/timeline, and all CA-mandatory home-improvement notices. → *Output: draft contract.*
2. **Compliance check** — contract carries required CA home-improvement notices (incl. buyer's right-to-cancel / Notice of Cancellation), CSLB license # and required disclosures, and the **deposit does not exceed the statutory home-improvement cap — [lesser of $1,000 or 10% of contract price; verify current CSLB figure]**. → *Output: compliance-passed contract.*
3. **Send for signature** via e-sign; capture the fully executed copy. → *Output: signed contract.*
4. **Collect deposit** within the cap; **issue receipt**; log to the Contractor Foreman deposit ledger. → *Output: receipted deposit.*
5. **Confirm funds** cleared before any downstream trigger. → *Output: cleared-funds confirmation.*
6. **Trigger + file** — start CON-002 (HOA 3–4 day clock) and PRO-001 (production handoff); file executed contract + receipt + locked estimate/plans together in the Dropbox project folder. → *Output: triggers fired, docs versioned.*

## Acceptance Criteria / QC
**No work is scheduled and no deposit above the statutory cap is collected without a fully executed, compliant contract.** Concretely:
- Signed contract contains all CA-mandatory notices, license #, disclosures.
- Deposit within statutory cap and receipted.
- Funds-cleared confirmation logged.
- Contract + estimate (DES-005) + plans (DES-004) versioned together in Dropbox.
- CON-002 and PRO-001 triggered.

## Exceptions & Escalation
- **Client wants to prepay above cap** → not permitted; explain statutory limit, structure via milestone schedule (FIN-001).
- **Financing involved** → route to Principal for financed-contract handling.
- **Scope change during signing** → re-issue through DES-005/DES-006; never hand-edit an assembled contract.
- **Non-standard terms / legal questions** → Principal + counsel before signature.

## Outputs
Executed contract + receipted deposit → Dropbox + Contractor Foreman. Triggers **CON-002** (HOA), **PRO-001** (production handoff), **FIN-001** (milestone billing).
