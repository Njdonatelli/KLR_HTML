## Purpose
Keep the CSLB license, contractor bond, insurance (general liability, workers' comp), and required registrations **current and verifiable**, so KLR can legally contract and is never exposed to a lapse that voids a contract or coverage.

## Scope / Trigger
Standing SOP, **quarterly** review plus event triggers (pre-contract, pre-sub-scheduling). Covers KLR's own credentials and subcontractor credential verification.

## Roles (RACI-lite)
- **Responsible:** Operations Manager
- **Accountable:** Principal
- **Consulted:** Insurance broker, counsel (coverage/requirements)
- **Informed:** Admin/Finance, Production Lead (sub scheduling)

## Systems & Inputs
- **Dropbox** — compliance register + certificates (`02_Areas/`, TEC-002).
- CSLB license record; bond; GL + workers' comp policies; business license; fleet/auto insurance; sub COIs + licenses.

## Compliance register (maintain currency + expiry)
| Credential | Note (verify) |
|-----------|---------------|
| CSLB license | Renewal cycle (typically 2 yrs); # appears on all contracts (CON-001) |
| Contractor bond | Current, correct amount |
| Workers' comp | Required with employees (HR-004) |
| General liability | Current; adequate limits |
| Business license | Local, current |
| Fleet/auto | Current for company vehicles |
| Subcontractor COI + license | Per active sub (PRO-004) |

## Procedure
1. **Maintain the register** — credential #, carrier, limits, expiry for every item above. → *Output: compliance register.*
2. **Quarterly review** of all expiries; calendar renewals **[60–90 days]** ahead. → *Output: review + renewal calendar.*
3. **Verify before contracting** — confirm license + insurance current before any CON-001 signature (license # on the contract). → *Output: pre-contract check.*
4. **Verify subs** — collect + track each sub's license + COI; **do not schedule an uninsured/unlicensed sub** (PRO-004). → *Output: sub compliance log.*
5. **Renew + file** — process renewals; file current certificates/COIs in Dropbox. → *Output: filed current docs.*

## Acceptance Criteria / QC
**KLR never contracts, and no sub works, under a lapsed license or insurance.** Concretely:
- All own credentials current and documented.
- Quarterly review performed; renewals calendared ahead of expiry.
- Pre-contract license/insurance check passed for every signed job.
- Every scheduled sub has a current license + COI on file.

## Exceptions & Escalation
- **Approaching lapse with renewal at risk** → Principal + broker immediately; hold new contracts if a required credential would be lapsed at signing.
- **Sub cannot produce current COI/license** → do not schedule; Production Lead sources an alternative.

## Outputs
Current compliance register + filed certificates → Dropbox. Gates **CON-001** (signing) and **PRO-004** (sub scheduling); supports **SAF-004** claims and **HR-004** classification.
