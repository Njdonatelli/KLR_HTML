## Purpose
Close the project with the client on-site (flyer step 7 — "we review the completed property together"): confirm the work matches the contracted scope, clear the punch list, collect final payment, and hand off warranty — converting a finished build into a signed-off, paid, referral-ready project.

## Scope / Trigger
Fires when PRO-006 marks construction complete and the punch list is ready. Covers the joint walk-through, punch resolution, sign-off, final billing, and warranty/referral handoff. Ends when the project is signed off, paid, and warranty-registered.

## Roles (RACI-lite)
- **Responsible:** Operations Manager (or Production Lead)
- **Accountable:** Operations Manager
- **Consulted:** Production Lead (punch items), Client (acceptance)
- **Informed:** Principal (disputes), Design Lead (design-intent questions)

## Systems & Inputs
- **Contractor Foreman** — punch list, final invoice (FIN-001).
- **Dropbox** — signed acceptance + warranty docs per TEC-002.
- Completed project + punch list (PRO-006), as-built photo records (FLD-002/003), milestone schedule (FIN-001).

## Procedure
1. **Pre-walk prep** — confirm punch list (PRO-006) and that all contracted + change-order (CON-004) scope is complete; assemble as-built photos and warranty docs. → *Output: walk-ready package.*
2. **Joint walk-through** — review the completed property with the client against contracted scope + plans (DES-004); capture any client-noted items. → *Output: walk punch list.*
3. **Resolve punch** — complete outstanding items; re-walk contested items. → *Output: cleared punch list.*
4. **Obtain sign-off** — client signs a completion/acceptance form confirming scope complete and accepted. → *Output: signed acceptance.*
5. **Final billing** — issue the final milestone invoice (FIN-001); collect balance. → *Output: final payment.*
6. **Warranty handoff** — register/issue warranty and care instructions (esp. planting/turf/irrigation + hardscape); log in CX-002. → *Output: warranty registered.*
7. **Referral/review ask** — trigger CX-003 while satisfaction is highest. → *Output: review/referral request sent.*

## Acceptance Criteria / QC
**A project is not closed until it is signed off, paid, and warranty-registered.** Concretely:
- All contracted + change-order scope verified complete.
- Punch list cleared (or remaining items documented + agreed).
- Client signed the acceptance form.
- Final invoice issued and balance collected (FIN-001).
- Warranty registered (CX-002); care instructions delivered.
- Referral/review request triggered (CX-003).

## Exceptions & Escalation
- **Client disputes completeness** → document specific items; Production Lead resolves; unresolved → Principal. Do not force sign-off.
- **Client withholds final payment** → Operations Manager + Principal; reference contract/lien remedies (counsel).
- **Latent issue surfaces at walk** → log to warranty (CX-002) or correct pre-sign-off depending on severity.

## Outputs
Signed acceptance, final payment, registered warranty, referral request → Dropbox + Contractor Foreman. Feeds **CX-002** (warranty), **CX-003** (referral), **FIN-003** (final job-cost reconciliation).
